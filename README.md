## Need Help? Images Look Stretched?

For PC and mobile users, follow these steps:

1. Click **'Autoscale'** (located next to the home icon) on each HTML file to properly scale the image.
2. If the image is too zoomed out, select the **'Zoom'** tool to click and drag to your desired area.
3. Once you have zoomed to the desired location, switch to the **'Pan'** tool (located next to the Zoom tool).
4. Make sure you are on the **'Pan'** tool (not 'Zoom') to click on individual points and see the recorded Sea Surface Temperature (SST) data.

This will allow you to interact with the map and view specific data points accurately.
